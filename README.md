# Secure Linux Server

## Description

This project is a practical Linux security laboratory.

The goal is to learn and demonstrate basic Linux system administration, security check, network monitoring and server hardening.

## Objectives

- Check basic system information
- Monitor active services
- Check listening network ports
- Check SSH check services status
- Practice Linux security concepts
- Develop bash scripting skills

 ## Technologies

 - Linux
 - Bash
 - SSH
 - Systemd
 - Networking
